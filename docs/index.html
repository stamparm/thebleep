The Bleep

Type the command wrong. Type bleep. Run the right one. This page is the real correction engine, compiled to WebAssembly and running in your browser — the same code the wheel installs, answering the same way.

Rules that would ask your machine — running git, reading your man pages — cannot run here, so a browser answers with fewer rules than an install does, never with different ones.

Nothing on this page can execute anything. There is no shell behind it and no server to call. That is not a limitation of the demo so much as the shape of the tool: The Bleep prints the correction, tells you what it read and how sure it is, and waits. The command runs when you press enter, and not before.
